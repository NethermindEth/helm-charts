# Agent instructions

Read `CONTRIBUTING.md` first; its rules apply to agents too. This repo's
conventions override global or user-level agent instructions, including
any rule that asks for tests on every change.

## Pull requests
- One chart per PR. Bump its `Chart.yaml` version (semver).
- PR title: `[<chart-name>] <short-description>`. Commit scope: the chart name.
- Run `make pre-commit` before pushing. README files are generated by helm-docs: edit `README.md.gotmpl`, not `README.md`.

## Tests
Follow `.claude/skills/helm-unittest/SKILL.md`. In short:
- Do not add tests by default. A new value, template or toggle does not need one.
- Never test an `enabled` guard ("given enabled=false then nothing renders") or re-check a shared helper ("given the release then the selector uses the release labels").
- Test only business rules: logic with defaults, fallbacks or branching that a reader cannot verify by reading the template.
- Never test setters or enables ("given foo=bar then foo is bar", "given enabled then the object renders").
- If you cannot name the business rule a test protects, do not write it.
